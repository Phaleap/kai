# Kai app (Flutter)

The mobile app for Kai. See the main [README](../README.md) for the full project.

```bash
flutter pub get
flutter run -d chrome
```

The server address is `baseUrl` in `lib/app_state.dart` (default `http://127.0.0.1:8000`; Android emulator: `http://10.0.2.2:8000`). Start the server first.
