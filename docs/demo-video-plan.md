| Time | Show on screen | Say |
|---|---|---|
| 0:00 to 0:10 | Onboarding: pick goal, level, days, injuries | "This is Kai, an AI fitness coach for beginners. I built the Flutter app, the FastAPI server and the AI agent." |
| 0:10 to 0:25 | Today screen, start the workout, log 2 sets of bench press 80 kg x 8 | "You log your real sets here." |
| 0:25 to 0:35 | Finish workout, celebration screen, Progress tab | "Progress shows personal records and history." |
| 0:35 to 0:55 | Coach tab: ask "What weight should I bench next time?" | "Kai calls a tool that calculates the next weight from my log, 82.5 kg. The math is done by code, not guessed by the AI." |
| 0:55 to 1:10 | Coach tab: ask "My knee hurts when I squat, what injury is it?" | "Safety rules: Kai never diagnoses and sends you to a doctor." |
| 1:10 to 1:25 | Terminal: run `python tool_eval.py`, show the score | "I test the AI with automated evals, like normal code tests." |

Then upload to YouTube as **Unlisted** and paste the link in the README where it says "Demo video: coming soon".
